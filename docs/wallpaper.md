# Wallpaper

**Show wallpaper on home** displays Android's wallpaper and is enabled by
default. Disable it for a black background without changing the system image.
The Android wallpaper picker remains available in preferences.

**Restore default wallpaper** changes the Android home wallpaper for all
launchers and asks for confirmation. A separate lock screen wallpaper is
preserved on Android 7 and later.

## Custom home image

Use **Choose home image** to import an image up to 32 MB through Android's image
picker. LauncherTV keeps a private copy without changing Android's wallpaper.

In **Home image scaling**, choose:

- **Whole image**: show every edge, adding black borders when needed.
- **Fill screen**: crop the center to fill the screen without distortion.

Photo orientation is respected. Canceling or importing an invalid image keeps
the previous image. Disable **Use home image** to return to Android's wallpaper;
the private image stays available until app data is cleared or the app is removed.
**Show wallpaper on home** controls visibility in both modes.
