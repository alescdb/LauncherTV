# Home screen

Open **Preferences** to change the grid, margins, labels and transparency.
Changes apply when returning home. Tiles outside a smaller grid remain saved
and reappear when you enlarge it.

**Lock icons** prevents tile and folder edits and grid changes. Preferences
remain accessible so you can unlock them. This setting does not require a PIN.

## Default launcher

Open **Preferences > Default home app**, select Simple TV Launcher in Android's
settings and confirm if requested. On older Android versions, press Home and
choose **Always** when the launcher chooser appears. If another launcher is
already selected, clear its default association in Android's application settings.

Some TV firmwares enforce their own launcher or hide this choice. LauncherTV
cannot override those restrictions.

## Applications, shortcuts and folders

With icons unlocked, select an empty tile or long press an occupied tile to
choose an application. Other launchers also appear in the picker: pin the TV
manufacturer's launcher to keep a route back to its home screen.

To add a shortcut on Android 8 or later, make Simple TV Launcher the default
home, then use the publishing application's pin-to-home action. Confirm the
shortcut in LauncherTV. On older versions, legacy requests are confirmed when
you return home. An empty tile is required; saved shortcuts remain available
in the application picker.

Choose **New folder** in the tile picker to create a folder. Open it and use
**Add** to insert applications or saved shortcuts. Long press an item to remove
it. Rename and delete controls are inside the folder. Deleting a folder does
not uninstall its applications. Folders cannot contain other folders.

## Status information

The home screen includes a clock. Date and battery display can be enabled in
preferences.

**Show network icon** and **Show IP addresses** are independent options, both
disabled by default. The icon distinguishes Wi-Fi, Ethernet, other connections
and no connection; it does not check Internet access.

The IP display lists local IPv4 and IPv6 addresses by interface. Select it with
the remote to open the full list. It distinguishes no connection, no available
address and unavailable information, and refreshes while home is visible.
